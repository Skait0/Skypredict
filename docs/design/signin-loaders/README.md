# Sign-in loader concepts (30 Sep 2026)

These are design mockups from the accounts sign-in brainstorm. Open any file straight in a browser: each one is self-contained and loops.

The theme is **wizardry x soccer**: dark #0D0D0F with gold #F2B84B, Plus Jakarta Sans for text and Roboto Condensed for numbers.

| File | Concepts | Status |
| ---- | -------- | ------ |
| 01-ticket-roll-board.html | Ticket print, Rolling ball, Split-flap board | Football only, no magic. Unused. |
| 02-summoning-crystal-tactics.html | Summoning Circle (90-minute clock), Crystal Ball v1, Tactics Spell v1 | First wizardry round |
| 03-tactics-spell-v2.html | Tactics Spell v2: 3D board, runes, vanishing defenders, goal | Owner's favourite |
| 04-crystal-ball-v2.html | Crystal Ball v2: trophy stand, plasma lightning, orbiting sparkles, tap quips | Kept for later use |
| 05-crystal-ball-v3.html | Crystal Ball v3: brighter visions, booking code, mini pitch inside | Kept for later use |
| 06-signin-sheet-draft.html | Two sign-in sheet layouts (pre-theme) | Draft, to be redone in theme |

The owner chose the **Tactics Spell** as the post-sign-in loader, pushed "crazier" in v3 (07). The others are saved on purpose: candidates for other moments, such as the empty state, the booking wait, the 404 page and share cards.
