Each colour does one job, everywhere

RedBrand and action. Book button, selected chips, Send, the ticked opt-in box, the wax seal, our players, passes, the net and the shockwave. The same red that fills the book button and the chips today.
GoldOdds and winning. Odds in the slip, total odds, the odds that float up as each player touches the ball (your real slip's odds), "✦ GOAL ✦" and the gold stars. Same meaning as the site's odds and win marks.
GreenHits only. Not used in sign-in, so it keeps its meaning.
NeutralStructure. Pitch chalk, rune ring, defenders and the empty player dots use the site's line and faint greys, like card borders.

Why it now feels like one site

The earlier mockups painted everything gold, which on the site means "odds". Now red does the talking, gold rewards, grey holds the structure, which is the same split as a fixture card with a Book button. The light theme works for free, because every colour is a site token.

Where to use it in the build: the sheet and the spell read only these tokens (--red-fill, --red-ink, --win, --faint …). No new colours are added to the site.
