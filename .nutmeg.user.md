# Soccerwizard

Live football prediction site at https://www.soccerwizard.live. Static-first:
one page (`public/index.html`), a Node build (`scripts/prebuild.js` + `lib/`)
that bakes `public/predictions.json`, and a Python API on Railway
(`~/Documents/soccerwizard-api`) that talks to four bookmakers.

Written from the repository and the current session rather than an interview.
Edit anything that is wrong.

## What the model is

Poisson-family goals model fitted on full-time results, with:

- country offsets fitted from 2024-25 and 2025-26 (48 fitted, rest imported
  from the UEFA coefficient; European home edge 0.0585)
- calibration shifts per market, measured against recent graded results
- a corners model (negative binomial, k=52.5, fitted over ~15,500 matches)
- tier costs so a lower division cannot outrank a top flight on confidence alone

It publishes tips across ~38 leagues and grades every one of them afterwards;
the published record is the product, not the tips.

## Where results come from today

1. **football-data.co.uk** - main files (the big European leagues) and the
   per-country "extra" files. The extras are the weak link: 30 leagues sit
   under the build's `minLeagueMatches: 60` bar since `minSinceDate`
   2023-07-01 and are dropped outright.
2. **SoccerVista** - harvested for the current season; their board only reaches
   about 7 days back, so a week not harvested is gone for good.
3. **API-Football** - the score oracle, capped at 3 calls a build / 100 a day.
4. **Bookmaker feeds** (SportyBet, Bet9ja, BetKing, Betpawa) - fixtures and
   prices, not results.

## The open problem

A day whose card is cup ties in unrated competitions prices nothing. Measured
23 Sep 2026: 1,325 SportyBet fixtures merged, 343 predicted, 826 unmatched,
658 of those "no league". The fix is results coverage for the dropped leagues,
not matcher work.

## Constraints

- Licence must allow a public, ad-free-but-commercial prediction site.
- Must be scriptable from Node (the build) or Python (the API); the build runs
  on Vercel with a ~50s budget and no persistent disk.
- No per-request paid calls in the build path. A daily or weekly pull that
  commits results to the repo or Supabase is fine.
